Shift Drift

Takes raw device punch logs, keeps each day's earliest IN, and flags clock-ins outside the assigned shift bucket — plus the Friday-early → Monday-late weekend-extension pattern.

Punch log columns

Required: an Employee ID column, a punch timestamp (Date + Time together), and a Direction column telling IN from OUT. Matched automatically by header name — override any of them here.

Direction mapping

Every distinct value found in the Direction column, and what it means. Only rows mapped to IN are used to find each day's earliest clock-in.

Employee / shift master columns

Required: the Employee ID column that matches the punch log's Employee ID, and ShiftCode. EmpName, Department and Designation are optional but make the tables more readable. If the same employee is assigned different shifts on different days, also map Date (one row per employee per exact calendar day) or Weekday (one row per employee per weekday, repeating every week) — whichever your roster export uses. Leave both unmapped for a simple fixed shift-per-employee file.

Shift bucket mapping

A = 05:30–07:30 · General = 07:31–12:00 · B = 12:01–16:00 · C = 20:00–23:00. Tell Shift Drift which bucket each raw ShiftCode from the master file is assigned to.
